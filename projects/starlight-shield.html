Starlight Shield

Java 代码保护工具

通过将 Java 字节码转换为原生代码，为您的应用程序提供多层安全保护，有效防止逆向工程和代码泄露。

01

核心特性

多层安全保护，全方位守护您的代码

数据加密保护

支持字符串和数组的多层加密保护，在运行时动态解密，有效防止敏感数据被提取。加密过程完全自动化，无需手动修改代码。

控制流混淆

将代码逻辑转换为状态机模式，插入虚假控制流分支，使反编译器无法确定实际执行路径，大幅提升代码分析难度。

指令替换

将简单的运算指令替换为复杂的等效运算，增加代码分析难度。支持多种运算类型的替换，包括算术运算、位运算等。

跨平台支持

支持 Windows、macOS、Linux 三大主流平台，覆盖 x86_64 和 AARCH64 架构。一次配置，多平台编译输出。

原生代码编译

使用 Zig 编译器将 Java 字节码转换为 C 代码并编译为原生库，代码不再以 Java 字节码形式存在，从根本上防止反编译。

灵活配置

通过 XML 配置文件精确控制混淆范围，支持 Ant 风格路径匹配。可选择性启用各项保护功能，平衡安全性与性能。
